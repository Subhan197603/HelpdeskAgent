# ADR-0009: Oracle document permission gate

- Status: Accepted
- Date: 2026-08-01

## Context

Automated acquisition of Oracle documentation may be contractually or legally restricted.

## Decision

Keep automated Oracle acquisition disabled unless recorded organizational permission is present and validated.

## Alternatives

Unconditional crawling and relying on operator memory were rejected.

## Consequences

Manual approved ingestion remains available; provenance and permission references must be auditable.
